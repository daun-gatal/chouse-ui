type: major

### Added
- **Readable output** — `-o auto` (the default) prints a table in a terminal and JSON when piped; `-o table|csv|json|yaml` picks one. Query results keep ClickHouse's column order, `--out FILE` writes them to a `.csv`, `.json` or `.yaml` file, and `--wide` / `--no-headers` tune tables
- **Secure login** — `auth login` reads the token from a hidden prompt, `--token-stdin` or `CH_HOUSE_PAT`; `--token` still works but warns that arguments land in shell history
- **Profiles** — `config view|get|set|unset|use-profile|profiles|delete-profile` for `server`, `connection`, `output` and `ca_cert`
- **Connection names** — `-c prod` works wherever an id did; an unknown name lists your connections
- **`--debug`** — traces each request (method, path, status, time, request id) without ever printing the token; errors show the server's request id and a hint
- **`--ca-cert` / `CHOUSE_CA_CERT`** — trust an internal CA (`auth login` remembers it); `--insecure-skip-tls-verify` is for debugging, warns and is never stored
- **`chouse mcp status|tools|config|settings`** — whether the server's MCP endpoint is on and its address (`<server>/mcp`), the tools your token gets, setup for Claude Code, Codex, Cursor, VS Code and OpenCode that reads the token from `CH_HOUSE_PAT`, and the administrator's MCP settings (read-only)
- **`chouse agents summary|sessions|session|policies`** — agent activity, session replay and budget policies (read-only)
- **Server compatibility** — `chouse status` reports the server version and whether this CLI supports it (3.14.0+)

### Changed
- **Reads retry on transient failures** — GET requests retry up to three times on network errors, `429` and `502/503/504`, honoring `Retry-After`; writes are never retried
- **Ctrl-C cancels the request in flight** and exits `130`; an unreachable server or a timeout exits `6`
- **Unknown subcommands fail** with exit `2` instead of printing help and exiting `0`
- **`chouse logs`** is one command (the `queries`, `patterns`, `tables` and `histogram` views all sent the same request) with `--user` and `--limit`
- **Argument shapes** — `saved create` takes SQL as arguments, `-f FILE` or `--stdin`; `upload preview <file>`; `fleet query <metric>` uses `-c`; `table schema|sample` also accept `db.table`; `table list [database]` shows one row per table; `connection list` shows the connections your token can use (no `connections:view` needed)
- **JSON field names follow the server** (`dryRun`, not `dry_run`)

### Removed
- **Commands that only pointed at the UI** — `connection create|delete|use`, `table create|drop`, `upload into`, and the deprecated `auth login --pat`
